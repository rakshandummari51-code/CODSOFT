# Credit Card Fraud Detection

This project detects fraudulent credit card transactions using Machine Learning.

## Features

- Data preprocessing
- Normalization
- Class imbalance handling using SMOTE
- Logistic Regression model
- Fraud detection

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Imbalanced-learn

## Machine Learning Algorithm

Logistic Regression

## Run Project

```bash
python fraud_detection.py
```
## Dataset

The dataset is too large to upload to GitHub.

Download the dataset separately and place:

```text
creditcard.csv
```

inside the project folder before running the project.
