# Titanic Survival Prediction

This project predicts whether a passenger survived the Titanic disaster using Machine Learning.

## Algorithm Used
- Random Forest Classifier

## Accuracy
- 84.35%

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Features
- Data Cleaning
- Label Encoding
- Feature Engineering
- Machine Learning Prediction

## Project Files

- main.py
- Titanic-Dataset.csv
- requirements.txt

## How to Run

Install libraries:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```

## Output

The model predicts Titanic passenger survival with approximately 84% accuracy.
